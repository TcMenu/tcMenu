# TcMenu Web Designer

Run `npm install` and `npm start` to start the Vite development server at
http://localhost:3000. API requests are proxied to the web generator backend at
http://localhost:8080, which must be running for backend features to work.

Run `npm test` for the interactive test runner, or `npm test -- --run` for a
single run. `npm run build` type-checks and builds the application into `build`.
